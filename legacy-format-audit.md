## Upgrade and recovery

Local conversion runs before affected data is opened. The migration journal covers raw files, configuration, account manifests/vault files, SQLite and old cache shards. A failed conversion restores original bytes/database contents and leaves the contract unchanged. SQLite stages decoded rows on disk so the typed-store conversion does not retain the whole database in Python memory. Canonical histories, token coverage, scanner checkpoints, peer ownership and collection periods are retained; obsolete chart/delivery caches rebuild from retained facts.

Cloud conversion runs inside the existing queued WebDAV operation and its exclusive lock, so nested requests do not add notifications. An encrypted migration journal retains mutable roots. New immutable payloads are uploaded and read back before root replacement. The cloud contract marker commits after conversion; old transport directories are removed only after that commit. Incomplete cleanup retains the journal for retry. A failed root conversion attempts all rollback steps and reports any paths still requiring recovery.

Migration-only compatibility readers remain necessary for sequential upgrades from already released contracts. They are packaged with the runtime but are imported only by upgrade code. Ordinary data loading does not perform those conversions.

## Verification

Coverage includes sequential upgrades, strict-reader rejection, local checkpoint rollback, shard restoration, historical usage replay coverage, cloud root rollback/retry, encryption-key preservation, old-pack conversion, skill package content, and existing account, processing, streaming, delivery and UI tests. Installed-data validation uses a private copy; it does not migrate live files or contact WebDAV.

The installed-data copy completed the 14-to-15 conversion with all 41,423 ledger rows retained, exactly matching token/cost totals before and after conversion, and passing SQLite integrity checks. Private validation copies were removed afterward. The release outputs and running monitor were not changed.
